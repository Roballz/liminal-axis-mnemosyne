# S-A：接入验证与工程地基

状态：in_progress。范围：T-00～T-03（含 T-02A 前置验证）。更新：2026-09-19。

## 1. 阶段目标

证明 Mnemosyne 能在隔离 TT 环境可靠接入生成链路，冻结自己的身份／版本契约，并建立可部署、可备份、可恢复的最小存储地基。

已接受先评估 B 本机版、后完善 A 独立服务器版；B/A 是部署方式，不是阶段编号。采用 B 不代表 A 已交付，正式存储 provider 仍须经过 T-03 选型和恢复验收。

## 3. 阶段完成线

阶段 A 结束时：隔离 TT 生成前接入可行性已证实；核心身份／版本契约已到可编码且可测试状态；选定 provider 的最小持久化、逻辑导出与空环境恢复经过验证。

若以 B 本机 provider 完成存储地基，必须明确报告 A 服务器、真实 B→A 迁移和手机生产使用尚未覆盖的部分；不得用桌面测试代替手机准入。具体平台/存储完成线在 T-03 从 proposal 转 planned 时确认。

本阶段不要求完成正式剧情导入、自动记忆、完整混合召回、自定义模块或 MCP。第一个可日常使用的档案／原文搜索闭环仍属于阶段 B。

## 4. 已确认输入

环境基线见 `notes/baseline.md`：Windows 10 x64、TT 2.2.0 dev/Canary（git `5e33bf6fead6`）、柏宝书 1.2.9 纯前端本地模式、`system @d0` 注入配置及当前副 API／embedding／rerank 模型。

用户已有电脑测试聊天与 ST／TT 导出能力；现用手机不用于首轮破坏性实验。长期 RP 主要使用单台手机，B 版单权威写入/明确交接已确认，不重复询问。

T-02 不沿用柏宝书 `Leaf` 作为正式对象名；普通派生按 User + Assistant 一轮一份，原文单独归档不意味着 User 单独摘要。

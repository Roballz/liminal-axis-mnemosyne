## 2. 本轮已定，不重新问用户

正式细则与依据见 `docs/11-stage-b-import-policy.md`。

- 导入是迁已有资料，不照搬柏宝书 schema。正文/摘要优先；物品、地点、生活档案可选；眼下局势、人物档案、变量、计划、旧向量/密钥/注入配置不导入。保留正文中的人物事实，不作文本脱意改写。
- 新资料正式 ID 属于 Mnemosyne；有确切映射才自动复用，未知同文也先确认。模糊判断和万能修复器留 T-13/T-14。
- 两个主选项：不继承的新聊天 / 继承已有存档。继承面板明确续聊或分叉及截止；已绑定聊天的普通编辑/重开不重复让用户选择新建。续聊不因换文件新建正文 Head，分叉固定父快照。
- 删除/复杂变更：警告 + 人工核对；受影响同步/记忆使用暂停，旧原文保留；确认后提交。不是让用户负责程序丢数据，也不是实现 AI 自动修复。
- 普通回合只承接一条 User + 紧接一条 Assistant，展示锚为 Assistant 楼层。连续角色、system、开场白等原文照存；不自动改造 LLM 输入、不强制历史全部标准化。T-04 不生成新摘要。
- 手动搜索默认当前 Story/Branch 有效正文；摘要可选辅助。正文原样保存，T-05 用独立规范化投影实现全半角/大小写和空白容错。物品按持有人检索等留实体功能。

## 3. 真正需要开工核对的输入

现有资料已记录原始 JSONL 可导出、TT 隔离环境、柏宝书固定 API 基线；不得反复索要已经提供的信息。

编码助手只需确认实际目标版本/可读入口、获准合成样本里的摘要字段与 coverage、可选 items/scenes/lifeDetails 的实际映射及既有存储接口如何保存最小桥接回执。缺少柏宝书运行样本时，正文路线仍可推进；缺少来源不能伪称全部派生数据完整迁入。

没有新的产品选项需要用户预先做技术选择。实际字段/权限/正确性超出确认范围时才回审。合成小样本可覆盖的事不要求先交出完整真实 RP。

## 4. 安全与权限门禁

TT/柏宝书是只读源；目标仅写新的受控 Mnemosyne 库。Stage-B“同步”不是 TT 数据库同步、整库归档替换或多人/多设备合并。

`HOST_MAINTENANCE_UNSUPPORTED` 保留；合作式维护仍须排空。真实长期档案、生产手机、新安装/共享实例、付费 API、强杀和清理均不由本阶段自动授权。源只读不消除目标维护风险。手机和规模表现仍为未验证，不借阶段推进改成通过。

## 5. 执行与测试预算

先难后易：导入身份/幂等与恢复 → 精确对账和暂停/确认 → 旧资料白名单映射 → 最小导入面板和报告。普通中途提交不是新增审批关卡，无新阻塞继续到 T-04 完成线。

只测任务卡列出的风险；先短反例、相关回归，最终候选稳定后一次全量。文档调整不测，代码未变/无新失败不重复测；日志落文件，只给统计和失败片段。不新增性能比较、1x/5x/10x或反复强杀矩阵。

小型隔离功能演示按既有许可执行；预计超过5分钟的原生循环、新破坏性测试必须事先说明目的/停止条件并获许可。停止新操作不等于取消正在发生的写入。参见 T-03 最终回执第4节。

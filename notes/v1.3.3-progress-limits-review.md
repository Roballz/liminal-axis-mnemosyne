# 1.3.3 进展字数与可编辑提示词

2026-09-25；基线 `002405f` / `work/daily-memory-mvp-baibai`，独立工作树 `work/progress-limits-100`。用户要求四类文字放宽到100字，并明确要求前端能修改实际发送给 AI 的最新进展提示词。状态：implemented_unverified，等待线上 review 和真实宿主验证。

## 实现

- 计划/悬念的内容、当前进展、仍待解决，以及事件链最新进展统一为100字。共享常量覆盖前端输入/保存、计划 delta 规范化与回放、主模型注入标题、事件 AI 返回与手动编辑校验、模型模板及追加协议、v7 核心包恢复校验。
- 保持现有计数规则，数字、字母、标点仍计数；事件来源剧情时间由程序单独附加，不占最新进展正文额度。事件概要仍为500字。
- 原先最新进展的写作规则藏在自动附加的 EVENT_OUTPUT_PROTOCOL 中。现在移到独立 EVENT_LATEST_PROGRESS_PROMPT；设置页新增“事件最新进展提示词”，与“事件概要提示词”相邻。通过 prompts.eventLatestProgress 保存；已有自定义概要原样保留，旧设置缺新字段时回落默认，留空/恢复默认仍有效。
- buildEventInstruction 组合当前概要写法、当前最新进展写法与必要输出协议；新建、加入后更新、显式 AI 重写、批量和自动更新均通过此路径。自定义进展写法替换其默认内容，默认规则不再藏在固定协议里重复发送。
- 两个事件提示词编辑器均可展开查看实际附加的输出协议；事件返回审阅示例也补上 latestProgress。设置沿现有 extensionSettings 深度监听保存机制持久化。
- 版本、manifest 缓存参数和生产 dist 升为1.3.3，继续使用无 source map 的小包上传方式。

业务与 UI 实现 +83/-32 行，测试 +50/-12 行；另外包含版本、构建产物和本记录。比初估实现范围扩大到独立设置项，是用户本轮补充的明确需求。

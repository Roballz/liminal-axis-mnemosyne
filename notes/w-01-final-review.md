## 改动与性能原因

1. 旧档案 / 表格页每次 mounted 都调用 `syncDaily()`：全聊天观察、保存元信息、canonical 同步、逐条加载正文/摘要。档案页还重复计算有效性；表格页将全量摘要渲染成勾选框。这是源码证据，与用户等待状态/按钮逐步亮起的描述吻合。
2. 原生摘要页主要使用已在内存的 `chat.extra.bbs_leaf` 和 `memory.summaries`。此次保留原生摘要页，移除档案默认正文/摘要列表和表格摘要选择列表；待审核项只在点击时加载。
3. 档案页直接显示后台归档状态；表列表只读取当前绑定和表定义，选表后才读该表行。页面不再以重新归档为打开前置，手工改表也不重新读取正文或摘要。
4. `syncDaily` 对未变宿主/Head/视图复用已完成缓存；仅事件/表格/审核 epoch 改变时复用正文视图再更新有效性。作用域、数据库、Head、选择、宿主版本和观察代次仍核对。
5. canonical 独立读取排队并行；来源/记忆版本未变化时跳过逐对象历史扫描；摘要有效性按共享基线/历史块读取一次，并用 Map 查询身份与依赖。有真实 inputRefs 的摘要不重新展开整段历史基线。
6. 原先注入循环每条摘要都执行 `hostVersion()`，反复序列化全聊天；改成每次构建注入视图只捕获一次允许集合。快路径仍在异步读取后复核宿主版本，不以去掉保护换速度。

没有宣称手机毫秒级，也没有将合成计数冒充用户设备耗时。首次归档、超大表单表 getAll、大库导出和手机后台存储仍可能等待；本轮不做生产手机容量压测。

## 自定义表与注入

- 表列表为入口，右键 / 长按 / `···` 管理表。设计页列出字段三行信息；单字段弹窗含名称、中文写入策略、类型、介绍、AI 填写提示词。行列表只预览前两字段，详情弹窗逐字段编辑，可拖动输入框右下角扩大。
- 支持长按进入多选、全选本页、隐藏 / 显示行、搜索与20行分页、改名和确认删除；删表/字段/行保留归档数据。
- 覆写、追加、首次写入后锁定；0/false 算已写入。AI 与手工编辑都拒绝改锁定值；用户可先修改字段策略。旧 manual 字段仍仅手动，不转成 lock。
- **同次原生摘要 LLM 请求**附加表定义、字段说明/提示词、当前可见行，并在原 JSON 根对象增加 `customTables` 的 add/update。单楼、用户自定义摘要提示词、包含最新楼的批量摘要均接线；无独立填表 API 请求。
- 纯历史补摘 / 高层压缩不读取当前表冒充历史状态。包含最新楼的批量摘要返回整批净变更；尚未具备自定义表完整历史状态重放。
- 结果先按 schema 和合法 ID 校验；表/行版本改变或宿主变化拒绝迟到结果。摘要与操作 ID 随聊天先保存，新库中各表行和回执同事务提交。明确无变化也留回执；失败显示对应楼号和可重试状态。
- 重摘同一楼会替代该楼旧未提交请求，即使摘要文本未变；已经提交的表格行/回执不回滚，不重复追加。核心包仍不包含未成功保存到库的宿主 sidecar，存在待处理时需先解决或另备份宿主聊天。
- 有效可见表行并入原 `mnemosyne_memory_state`：D1 / D2 跟随原状态位置；仅摘要模式关闭状态注入。隐藏行既不发给摘要 AI，也不发给正文模型；关闭自动填写不等于隐藏。
- 事件仍独立整理，召回补充在原候选最终选中后，与摘要/原文和知识库合并进原召回槽，使用原混合召回注入深度。页面和使用说明逐项解释间隔、延迟、批量、链数与额外进展。

## 数据、兼容与重要实现选择

1. canonical事实与向量投影独立。IDB事务中只作数据库请求；hash、模型与网络在事务外。历史清单按128条引用分块共享，追加不复制整段正文。
2. saveChat与IDB不伪装成原子事务。宿主消息身份先保存；宿主metadata保留pending；失败可重复观察重试，不换ID盲写。前端另显示错误。
3. L0实际正文引用记录在生成前；非标准回合完整归档但不伪造User+Assistant coverage。旧资料无证明时保留声明。高层保留实际child版本依赖；旧生成上下文不补造。
4. 上游自己写入的物品/变量旁注会产生正文新版本。仅完全匹配本次程序写出的内容、且其它实际输入未改变时，写`origin=generated_sidecar`兼容事实；生成inputRefs不改。用户编辑走人工review。
5. 事件概述只追加。元信息/关联/进展/回执同事务；人工关联使用保留历史的锁定修订。失效或被移除关联依赖的段不注入。
6. 全量目录与本批材料采用明确字符预算；先确定批次截止再读取目录，不带后面楼层的事件信息。事件额度默认2链、每链最多1额外摘要、1600总字符，设置可改。
7. 默认不开自动事件调用。手动补齐固定目标、逐批推进；停止不冒称取消宿主请求。needs_review持久化并等待人工处理，不自动反复付费。
8. 自定义表用固定stores。删表/字段/行确认后逻辑隐藏，旧字段单元格保留但不再发给AI；类型改变要求新字段，不偷偷转换历史值。自动周期填表未做。
9. 根部保留可安装产物。物品/地点/生活档案、时间/地点与原UI继续读取旧聊天delta。独立公共接口/按钮/设置/注入命名避免静默覆盖原扩展。
10. 迁移核心包明确排除宿主聊天/delta、知识库、索引、密钥。旧知识库另有显式只读复制本地文件与向量入口，按完整embedding身份判断可用；不称核心包为完整柏宝书备份。

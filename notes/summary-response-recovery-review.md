## 行为

摘要页新增“摘要返回记录”。每个请求保留每次重试的原样正文及错误，区分 API 抛错未拿到正文、空正文、解析失败、校验或写入失败、已应用。

失败返回可编辑 JSON，再点“确认应用（不调用 API）”；复用原解析器、表格校验及写入流程，不重新发 API。确认时复核聊天数组身份、聊天 scope、实际使用的楼层前缀（正文 / swipe / 已有摘要）、历史摘要依赖及父节点关系。B 模式重捕获证据，必须同分支、同 inputRefs 且依赖仍有效；事件材料、表格版本和最新楼层政策也复核，异步校验后再断言新证据。较后独立楼层成功不会使较前失败记录自动失效。目标或来源改变时，正文仍可看但旧结果拒绝写入。已成功请求的任何旧尝试都不能重复应用；批量回退已有成功楼时，也不能拿旧整批结果覆盖。

手动返回从全局弹窗审阅，楼层卡 / 档案页入口也能看到；请求结束先释放 busy/currentRun，关闭只收起弹窗，不写摘要，草稿可重开。手动检测总结每次准备首条符合条件的结果，不在确认前连锁生成。自动及批量不会逐楼弹窗，现有有限重试与逐楼回退保持。人工复用不触发新的自动上层 API 请求。新回放功能不保证修复数据已经变化的旧请求。

保留为插件进程内最多 20 次请求（跨聊天总数，每个聊天只显示所属记录），优先淘汰已经应用的成功记录；未应用记录仍超过 20 次时，淘汰最早一条。窗口关闭、页面组件卸载后记录和编辑草稿仍在；刷新 / 重新加载插件会清空。未新增数据库字段、远程遥测、真实 RP、凭据或生产日志。此前已丢失的失败输出不能追溯恢复。

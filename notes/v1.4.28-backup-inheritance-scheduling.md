# v1.4.28：备份、继承与后台检索调度

基线：`525bc1f9a9b72c158bbe01dbaa3846089e0db05e`，分支 `work/daily-memory-mvp-baibai`。

本批按用户顺序处理 **F25–F27、S01–S07**。F11 的回收策略仍未修改，留到下一批单独处理。

## 备份与迁移

- **F25**：手动备份、固定副本、恢复前保护、核心包导出、磁盘恢复和浏览器文件导入接入现有 Worker 协议。完整包的 IndexedDB 读取、严格 JSON 解析、序列化、哈希和领域校验留在线程中；UI 只接收 Blob、小预览或已验证的新库名。
- 恢复仍先写入独立新库并验证。主线程在既有 `serializeDailyActivation` 边界内读取恢复设置、复核页面/聊天/选择令牌，再切换活动库；取消或失败不启用候选库，原库保留。浏览器文件导入导出不依赖 TT 原生磁盘接口。
- 原生磁盘 RPC 按任务限制：详情仅读所选文件；固定副本仅写新固定文件；导入/导出不访问原生磁盘；仅自动备份可轮换删除。Worker 失败或超时时仍等待已发出的原生 IO 返回后才释放写队列，不能把终止 JS 当作取消磁盘写入。
- 领域校验使用有界的快照位置索引、分支快照分组和一次引用根收集，避免每分支扫描全部证据。旧包 v1–v15、来源/变体、引用身份、计数、正文哈希及校验和规则保留。
- **F26**：同一轮只记住已验证 baseline 与新写读回文件的字节大小和 SHA-256。轮换时仍重新读盘、校验原始字节摘要，精确相同才复用本轮验证结果；内容改变继续完整解析校验，下一轮不复用这些凭证。未用文件名、侧车预览或包内声明的 checksum 代替真实内容证据。

手动备份/迁移现在与自动备份一样要求宿主允许 Worker。不可用时给出明确错误并保留原库，不在主线程退回整包重计算。文件大小上限和严格 JSON 边界保留。

## 继承与历史投影

- **F27**：摘要匹配的精确签名按候选各生成一次，保留多候选拒绝规则。依赖按 family 解析并按调用缓存旧修订；建立反向依赖队列，失配继续撤销所有受影响祖先。现代继承凭据优先；旧事件按精确历史签名建立候选表，重复历史签名只计一个父卡，失效/blocked 父卡仍参与歧义判断，不误加重复事件。
- 分叉使用同消息的有序来源索引和按修订查找，保留重复消息的首匹配与 role repair 的方向性。旧依赖、人工审核和表格证据仍复制为子分支自己的身份。正文校验独立请求一起发出，每项立即转为 boolean，不额外保留一整份正文副本。
- 事件历史按 epoch 前进一次维护成员状态，只保留当前 family 状态；最后恢复原降序与同 epoch 顺序。删除关联的操作 cutoff 和未署来源文本的时间边界保留。
- 嵌套摘要的来源证明用共享子节点，不把全部后代楼层集合复制到每个祖先。每个精确 `(snapshot, cutoff)` 复用检查结果，最多缓存 32 组；显式栈处理深链，保留失败短路。
- 表格历史兼容检查按共享块及绝对偏移比较前缀，同一快照只读一次，正文与 swipe 身份分别核对；没有把不同位置或不同变体混为可继承。

## 高频通知与检索

- **S01**：不可变清单块在同一个 IndexedDB 事务内共享读取，refs/variants 不再重复克隆相同块。put/add/delete 立即使对应缓存失效；新事务、其他连接不共享缓存。普通可变 store 不缓存。
- **S02**：将完整设置克隆移入 200 ms 防抖，最长 1000 ms 刷出；提供显式 flush 与 pagehide 刷出最新值。初始化和迁移保持即时写入，共享渠道与排除名单独立及时广播且防回环。离开页面时保证交出最新宿主内存快照，不承诺宿主服务器一定完成落盘。
- **S03**：公共 revision 使用浅监听，森林保留独立深监听。rev-only 不遍历森林，实际正文、时间、子列表和数组变动仍通知，同 tick 变动仍合并一次。
- **S04**：每个候选向量只算一次模长，保留原点积除模长的算式与累加顺序，不重新量化候选；完全不匹配的维度不评分。
- **S05**：signal 传到本地向量、知识向量和后端请求。每 96 项让出前后检查取消，停止剩余评分及后续 scope。BM25 主线程一次派一个任务；取消排队项只移除该项，取消在途项终止它独占的 Worker 并为后继任务重建，旧回信不污染新任务。
- **S06**：BM25 先返回命中，之后在线程的下一任务序列化/保存。generation/revision 限定保存确认，最多一个在途保存及最新待存版本；旧保存不能清掉新 dirty，失败保留脏状态供后续检索重试。等待保存期间不宣称 persistent 成功，不改变可重建缓存文件格式。
- **S07**：query 向量就绪后，知识、BM25、摘要向量检索同时启动。每路保留独立成功/失败结果，在当前 run/取消令牌复核后才发布调试与注入结果；最终仍各自验证来源/版本，单路失败保留其他路，注入顺序和额度不由完成先后决定。

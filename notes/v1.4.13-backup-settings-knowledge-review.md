# v1.4.13 集成回执

基线：已发布 611653607e89eb8fc8ea0395f30c935f5936634e（v1.4.12）。

## 已实现

- 备份目录先列文件名；最多 256 条的轻量预览缓存仅展示，不用作恢复、固定或轮换依据。旧文件无需全量扫描。选中后只读 Worker 验证目标；改选/刷新/卸载拒绝过期回填。恢复和固定仍重新严格校验，20 份轮换及历史文件保护保持原样。
- 活动核心库切换前加载规范化 daily-settings；文件/磁盘恢复均生效。读取或选择器写入失败不改变原库。同步代次阻止旧库异步设置覆盖新库，包含同一微任务轮读取完成的回归反例。
- 知识库分隔符随常规设置持久化。编辑入口位于启用/停用与导出之间，显示全文，允许纵向缩放，保存为蓝灰填充浅色边框深色文字，取消透明。
- 新导入保留解码后完整原文；旧文档明确为区块还原。编辑保存正文并停止旧向量召回，再重新切块和向量化；失败保留新正文可重试，保持文档 ID、角色和启用状态。版本隔离及事务检查拒绝过期模型/编辑/删除结果。

## 边界与恢复

DB3 / 核心包 v14 不变，不搬迁主存储，不清理历史保护文件。知识库仍不包含在核心包中。真实 TT/Android、设备拖动、磁盘耗时和真实 Embedding 尚未验证；保存编辑会使用用户配置的 Embedding 并可能收费。

Worker 不可用时备份目录可显示，但磁盘面板详情/恢复/固定保持未验证；不偷偷退回主线程整包解析。手动导出的核心包文件导入仍可用，但不直接接受原生磁盘包外层封装。实际恢复的目标文件重读和新库写入未全部移至 Worker，不能声称恢复全程无主线程成本。

新版知识库追加了原文和版本化向量作用域，回退旧代码不保证能理解新版索引。回退前独立导出知识库文本并保留核心备份；不应以旧代码重写唯一副本。无真实用户文件、密钥或生产日志进入仓库。

# 1.3.10 共享原文删除修复与编辑后摘要弹窗

基线 d7fc6ee（1.3.9），工作树干净。只做单档删除，继续禁止连带删除分支。状态 implemented_unverified；手机/实际宿主 UI 待用户复核。

## 根因与修复

原文版本属于稳定消息身份；同消息、正文、角色完全相同时，归档复用已存不可变版本，不限定该版本最早由哪条分支入库。这是共享存储，不是自动用子分支正文覆盖父分支。旧删除算法却将 provenance.binding 的首次入库来源当成独占归属，企图删除其他分支仍使用的版本，随后被完整性校验拦住。

删除预览现在检查剩余快照、摘要来源、审核引用和分支修复引用。仍被引用的原文版本完整保留；原绑定的必要历史来源凭据存入版本化 retired-source-bindings 记录，原文内容、版本 ID、provenance 均不修改。活动分支和绑定按原计划删除，最小来源凭据不再是可继续归档的活动绑定。后续显式删除使来源不再被引用时，可清理该来源及无引用凭据。存在真正子分支或其他不可拆引用仍拒绝单档删除。

核心包升级 v9，支持读 v1～v8；校验历史凭据的字段白名单、故事、重复/活动 ID 冲突以及实际原文引用。未增加 IndexedDB store/version。新版核心包需要 1.3.10+；降级不能读取 v9 或理解历史来源凭据。

## 编辑后弹窗

设置 → 摘要设置 → “编辑后弹窗处理摘要”，默认关闭，沿现有宿主设置保存/恢复。

开启后监听宿主正文编辑以及显式手工摘要编辑，待原有派生/归档防抖完成后读取当前待审核摘要。存在待处理项时，在扩展面板关闭的聊天界面也可显示三按钮弹窗：保留摘要、更新摘要、过后处理。无待处理项不打扰。过后处理/关闭不改审核状态；模型不会因弹窗打开而调用，只有用户选更新才执行。

保留复用 keepSummaries；更新从已有内部面板抽出同一依赖顺序重建函数，逐条保存，失败保留已完成部分，不重写事件概要。内部待审核面板保留，供过后处理。确认前复核宿主/分支/代次，切聊天或关闭开关撤销排队弹窗。设置关闭、延后、过期选择均不批准旧来源。

## 验证与边界

- 只对用户提供包做本地限定字段/引用统计，不输出剧情正文，不修改上传 JSON，不将真实数据纳入仓库。
- 在隔离 fake IndexedDB 中读入该包，预览并模拟删除指定叶分支，核对剩余分支、快照、摘要、审核与事件记录逐条保持原样，再导出恢复比对，验证通过。此为内存模拟，不是删除用户生产库；临时检查脚本已移除。
- 复现等价合成反例：父分支复用子分支首次入库版本，删除子分支后保留原文与来源，父视图不变；缺失来源凭据的坏包被拒；后续删除最后档案可回收来源。
- 弹窗覆盖关闭开关、过后处理零审核写入、保留原路径、更新调用原楼层重建、重复编辑/切聊天旧选择拒绝、宿主编辑事件触发、排队后切聊天取消。
- 全量 npm test：34 文件、485 测试通过；timeRel 810、vector depth 12、memory regression 53 断言通过。vue-tsc --noEmit、npm run build、git diff --check 通过。构建仅保留已有大分包提示；dist/manifest 同步 1.3.10。
- 新弹窗/共享动作/编辑信号模块共148行，删除与迁移约54行新增，旧内部面板移除重复重建循环；合成测试约102行新增。准确行数以提交 diff 为准。

永久删除仍由用户在页面预览并确认；本次不替用户执行真实删除。回退代码不恢复已删除档案，也不能使旧版认识 v9 凭据，恢复依赖删除前核心包和兼容版本。实际 Android 上的弹窗展示、编辑事件顺序及删除按钮现场结果仍待复核。

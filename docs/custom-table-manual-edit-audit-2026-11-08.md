# 人工修订摘要后的自定义表整行注入遗漏修复

基线：`04391b7ee879125d5b3f082f828b457055f571fe`（1.4.34），分支 `work/daily-memory-mvp-baibai`。本次发布版本：`1.4.35`。

状态：implemented_unverified。已用合成数据验证真实摘要保存函数、Vue 楼层卡片保存入口、bridge 注入及本机档案导出恢复；未读取用户真实 RP 数据，未在用户 Android TT 实机验证。

## 原因与复现

1. 1.4.34 只兼容 `sameNarrativeRevision()` 认可的标签变动。编辑摘要文字并保存后，`editLeafAt()` 记录人工修订标记，canonical 创建新的摘要版本，内容、来源声明以及部分基线字段发生变化，旧表行保存的来源 ID 不再通过该判定。
2. 表行要求所有来源均可用，因此只要其中一条来源被人工修订，整行都会被过滤，表现为其他行完整、个别行完全消失。行的单元格本身并未丢失。
3. 楼层卡片的“保存摘要文字”原来调用 `editLeafFull()`，还会执行正文附注重写。旧格式附注可能因单纯校字而发生变化，引发额外的正文版本与表历史校验。本次将文字保存改为 `editLeafAt()`；结构化编辑继续走原来的完整保存入口。

在 1.4.34 上通过真实 `editLeafAt()` 复现：表内有 `S-001、S-002、S-003`，其中 `S-002` 引用待修改摘要；只修订摘要措辞后，注入仍包含前后两行，却完全没有 `S-002`。旧兼容摘要和生成附注两种来源均复现失败。

## 修复范围

- 新增只用于表格投影的 `createTableSourceValidator()`。旧版本表行可沿同一摘要 family 的人工修订继续使用，但旧、新双方的正文身份、来源顺序与范围、覆盖范围、锚点和 swipe 必须仍与当前视图一致。
- 人工修订使用已经持久化的 canonical 声明识别，不增加字段或迁移。已有的人工校字、连续多次修订、行内累积多个历史来源 ID 均可重新校验，无需逐条重新保存摘要。
- 允许旧兼容摘要的基线前缀转为人工版显式来源；后来追加、不属于原摘要的聊天尾部不会改变原来的来源范围。
- 依赖按原顺序、同 family 验证旧、新版本。先修改后续摘要、再修改其依赖摘要时，即使全局状态仍是 `needs_rebuild`，来源正文未变的已提交表行仍可用。全局摘要状态、事件概要和高层摘要的失效规则保持原样。
- 对生成时正文附注引起的版本差异，只认可原摘要版本自身的精确 `generated_sidecar` 回执，并核对回执快照、来源、覆盖、依赖和 swipe。普通“人工保留”审核不能代替正文未变的证明。
- 已继承到当前分支的摘要可以使用其保留的父分支基线；摘要身份仍严格限制在当前分支，同 story 的父分支摘要 ID 不会因此被注入。
- 缺失来源或必要基线、真实正文改动、相同文字但换 swipe、来源范围扩大、私有/禁用/删除、跨分支来源以及一行内其他失效来源均继续拒绝。缺证时不猜测、不扫描历史寻找相似文本。
- 正文状态注入、增量表格刷新和摘要填写上下文共用此判定。1.4.34 的名称自然正序及异步读取后的最终版本检查保留。

## 性能与数据影响

来源读取按实际可见行的唯一来源 ID 去重，当前合法来源保持快速路径。依赖、快照、清单块、生成回执和验证结果只在本次调用中读取一次并复用；旧基线前缀按共享 block 和 offset 缓存比较进度，不为每条旧摘要展开完整历史 refs 或复制全量索引。

显式来源数组仍逐项核对，以保留范围及顺序校验。已捕获的 refs/variants 和已加载的块使用同步 `cachedPoint()`，避免在每个引用上创建和等待 Promise；只在所需块尚未读取时异步查询。不存在循环依赖等待，递归用进行中 family 集合保守拒绝循环。

200 行共用一个旧来源的回归只读取该旧摘要一次；快照和块不重复读取，不读已退休的正文字符串，不做正文 hash，不扫描摘要版本全表。无变化同步与连续 20 次注入 getter 不重新扫描表格、历史或摘要。没有新增监听器、定时任务或后台刷新。

兼容校验只读，不重写表格定义、单元格、行来源或表历史。不会恢复此前因真实正文变化已经回退的表历史。已有副本缺少精确生成回执时仍保守拒绝，未新增跨版本历史搜索。

## 更新与回退

更新到 1.4.35 并重新加载扩展/聊天后，正常同步会重新识别仍在表内且原正文未变的旧来源。无需重跑摘要、重新填表或重建索引。

回退时同时恢复本次源码、版本清单与 `dist/index.js`；没有数据库迁移需要撤销。源码与合成测试结果不等于已验证用户现场所有遗漏行，实机验收仍待用户更新后确认。
